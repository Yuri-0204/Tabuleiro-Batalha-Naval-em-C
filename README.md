# 🚢 Batalha Naval

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um jogo de tabuleiro **Batalha Naval**, utilizando a linguagem de programação C. O objetivo é aplicar os conceitos aprendidos nas aulas de linguagem de programação por meio de um jogo interativo, no qual os jogadores tentam localizar e afundar as embarcações do adversário.

## 🎯 Objetivo

Desenvolver um jogo funcional que simule a experiência do clássico Batalha Naval, trabalhando conceitos fundamentais da programação e da construção de algoritmos.

## 🛠️ Tecnologias utilizadas

- **Linguagem:** C
- **Compilador/IDE:** Dev-C++
- **Versionamento:** Git e GitHub

## 🎮 Como funciona o jogo

O jogo utiliza um tabuleiro representado por uma matriz, na qual são posicionadas as embarcações. Durante a partida, os jogadores realizam ataques indicando as coordenadas do tabuleiro, tentando acertar as posições ocupadas por cada parte de uma embarcação. Após a embarcação afundar você vai poder identificar se ela é um barco, um navio, um submarino ou um porta avião. 

### Peças por Embarcações
Barco possui 2 peças
Navio possui 6 peças
Submarino possui 5 peças
Porta Avião possui 4 peças

## 📚 Conceitos de programação aplicados

- Variáveis e tipos de dados.
- Estruturas condicionais (`if` e `else`).
- Estruturas de repetição (`for`, `while` e `do while`).
- Matrizes e vetores.
- Entrada e saída de dados.
- Funções e organização do código.

## ▶️ Como executar

1. Clone este repositório ou baixe os arquivos do projeto.
2. Abra o arquivo-fonte `.c` no Dev-C++.
3. Compile o programa.
4. Execute o jogo pelo ambiente de desenvolvimento.
